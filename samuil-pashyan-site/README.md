# Samuil Pashyan — fan-made website

Современный одностраничный сайт про авто-мото блог Samuil Pashyan.

## Как запустить

1. Открой папку `samuil-pashyan-site` в Visual Studio Code.
2. Установи расширение **Live Server** (Ritwick Dey), если его ещё нет.
3. Нажми правой кнопкой по `index.html` → **Open with Live Server**.
4. Сайт откроется в браузере.

Также можно просто дважды кликнуть по `index.html`, но Live Server удобнее при редактировании.

## Что есть на сайте

- большой hero-блок с фотографией Самуила;
- расширенный раздел «О Самуиле»;
- хронология контента 2021–2026;
- раздел техники, появлявшейся в роликах;
- 6 выбранных YouTube-видео;
- отдельный архив заметных роликов с публично зафиксированными просмотрами;
- LIVE-счётчик подписчиков YouTube через SocialCounts;
- фотогалерея из загруженных фотографий;
- блок фактов о контенте;
- ссылки YouTube, Instagram, VK, Telegram и Twitch;
- FAQ;
- адаптация под телефон и планшет;
- анимации, lightbox и интерактивные элементы.

## Файлы

- `index.html` — структура и тексты;
- `styles.css` — весь дизайн;
- `script.js` — меню, анимации, галерея, метаданные видео и FAQ;
- `assets/` — локальные фотографии Самуила.

## Важно

YouTube-превью, автоматические названия роликов, Google Fonts и LIVE-счётчик загружаются через интернет. Локальные фотографии из `assets/` работают без внешних источников.

Разделы об истории и технике построены только по открытым публикациям и видеоархивам. Формулировка «техника в роликах» специально используется вместо утверждения, что вся перечисленная техника сейчас принадлежит Самуилу.

Сайт является fan-made концептом и не публикует непубличные личные данные.
